# ep001 制作ノート

**タイトル:** 毎朝聞いてるあの鳥の声、実は道路の"格"を伝えてる
**尺:** 約11〜12分 / 対話162行
**出演:** ハヤシ(解説役) / サカイ(リアクション役)
**設定:** 金曜の夜、居酒屋のカウンター。ジョッキ2杯目あたり

セリフ本体は `ep001_timeline.jsonl` が正本です。合成用に読み下してあるため、
表記は台本表示用とは一部異なります(「……」→「、」、数字→読み仮名 など)。

`ep001_meta.json` の既定は台本の文体（同僚二人の居酒屋トーク）に合わせた男性2人です。

| 役 | speaker_id | 声 |

| ハヤシ(解説) | 11 | 玄野武宏(ノーマル) |
| サカイ(リアクション) | 13 | 青山龍星(ノーマル) |

`--casting as_specified` で ずんだもん(3) / 四国めたん(2) にも切り替えられます。
別のキャラを試す場合は `casting_presets` に追記してください。

## SE仕様（実演コーナー / 本エピソード最大の見せ場）

`assets/se/` に配置すると自動で挿入されます。未配置なら指定尺の無音で
タイムラインだけ維持してビルドが通ります。

| ID | ファイル | 仕様 |
|---|---|---|
| SE01 | `se01_piyo_left.wav` | 擬音「ピヨ」×3 / **左chのみ** / 間隔1.2秒 / 尺5秒 |
| SE02 | `se02_nakikawashi.wav` | 「ピヨ」(左) →**0.8秒**→「ピヨピヨ」(右) を2往復 / 尺7秒 |
| SE03 | `se03_melody.wav` | 通りゃんせ風オルゴール / 左右ほぼ均等・ステレオ幅広め / 尺8秒 |

- パンは**振り切らない**。左右60〜70%程度＋浅いリバーブ。振り切ると
  「ヘッドホンの中の音」になり、「向こう岸」に聞こえません。
- SE02の0.8秒が命。短いと「同時」に、長いと「別の音」に聞こえて、
  音が渡っていく感じが出ません。実際に耳で詰めてください。
- SE03は**わざと定位を曖昧に**。ここで「分からない」を体験させないと、
  後半の雑学③(メロディが廃止された理由)が理屈だけの話になります。
- **SE01〜03をエピソード冒頭で鳴らさないこと。** 【02:36】が初鳴りだから効きます。
  それ以前の擬音は全てハヤシの口真似で処理してあります。
- SE03のオルゴールは権利処理済みの自作音源で。既存音源の流用は避けてください。

## リアクション設計

サカイの驚きは強さを変えてあります。①軽い驚き → ②身体反応(足がすくむ) →
③実演での実感(動いてる/指が上がらない) → ④理解の驚き(スピーカーが二つ) →
⑤笑い(通りゃんせの歌詞) → ⑥倫理的な気づき(夜) → ⑦感心。
同じ「えー！」が7回続くと12分は保ちません。

「立ってる人は目をつぶらなくていい」の一言は削らないでください。満員電車での
聴取が前提なので、この配慮だけで番組の信頼感が変わります。

## 収録前の裏取り（必須）

- 「カッコウ＝主道路 / ピヨピヨ＝従道路」の対応と、擬音式へ統一していく方針は、
  警察庁の指針・仕様の一次資料で確認すること。地域や設置時期による例外運用があり得ます。
- スマホ連携(高度化PICS)は名称を出さず噛み砕いてあります。機能範囲は最新の公式情報で確認を。
- 夜間の音量調整・停止は自治体ごとに差があるため、「そういう運用がある」までに
  留めた表現にしてあります。断定を足さないでください。

## ラウドネス基準について

既定は **-16 LUFS**（`ep001_meta.json` の `master.target_lufs`）です。
-16 LUFS は Apple Podcasts の推奨値で、Spotify の正規化目標は -14 LUFS です。
配信先を Spotify に合わせるなら `--lufs -14` で上書きできます。
